# AN.KI — сайт

Статический сайт. Без сборки, без бэкенда, без серверных зависимостей.

## Структура

```
index.html                     HOME
systems.html                   SYSTEMS
architecture.html               ARCHITECTURE (услуга «Архитектура систем», анкета)
tools.html                      TOOLS (каталог, пуст до появления реальных инструментов)
image.html                      IMAGE (услуга «Архитектура образа», анкета)
private.html                    PRIVATE (два формата: сессия и анализ)
questionnaire-session.html      анкета — Приватная сессия
questionnaire-analysis.html     анкета — Приватный анализ
questionnaire-image.html        анкета — Архитектура образа
questionnaire-architecture.html анкета — Архитектура систем
about.html                      ABOUT
assets/css/style.css            общие стили
assets/js/main.js               язык, мобильное меню, реальная отправка анкет
assets/img/                     фоновые изображения
```

Анкеты доступны только со своих родительских страниц (PRIVATE, IMAGE, ARCHITECTURE), в главном меню не отображаются.

## Публикация на GitHub Pages

1. Залить содержимое этой папки в корень репозитория (или в ветку `gh-pages`).
2. В настройках репозитория → Pages → выбрать источник (ветка/папка).
3. Дополнительная сборка не требуется — сайт статический.

## Язык

RU/EN переключается кнопкой в шапке и в подвале, выбор сохраняется в `localStorage` и остаётся при переходе между страницами. На данный момент заполнен только русский текст (`data-ru`); английский появится позже — переключение на EN пока оставляет русский текст без изменений.

## Формы

Все четыре анкеты отправляются напрямую в Formspree:

```
https://formspree.io/f/xjgnypww
```

Каждая форма передаёт скрытое поле `request_type` со значением, обозначающим тип заявки:

- `private_session` — Приватная сессия
- `private_analysis` — Приватный анализ
- `image_architecture` — Архитектура образа
- `system_architecture` — Архитектура систем

Отправка идёт через `fetch` (AJAX): сообщение «ПОЛУЧЕНО» показывается только при подтверждённом успешном ответе Formspree. При ошибке показывается сообщение с просьбой повторить попытку, введённые данные не сбрасываются. Никакой имитации отправки в коде нет.

Чтобы сменить получающий Formspree-эндпоинт, замените `https://formspree.io/f/xjgnypww` в атрибуте `action` каждой из четырёх анкет.
